火尖枪的火系特攻

持火尖枪进行普通攻击时，若目标是龙蝇、火狗、红鹿、红犀牛、岩浆虫或目标正处于燃烧状态，会额外附加一次与该次武器伤害相等的伤害。火尖枪本体基础伤害为 51，因此在这些条件下，它的普通攻击会明显优于其他开局武器。

这项加成按普通攻击的额外伤害段计算。

项目 规则
装备限制 仅哪吒可装备；被其他玩家捡起会自动掉落
普通攻击 51 伤害，无耐久消耗

混天绫

项目 规则
装备槽 身体；仅哪吒可装备
移动 装备后移速 ×1.1
初始燃料 100 点
充能材料 专属类型“莲花”；每朵补 10 点燃料

混天绫在燃料充足时抵抗指定伤害类型，不改变饥饿、温度、理智或常规移动与攻击；燃料耗尽时防护失效。

莲花、莲藕与莲子

哪吒可在自己的神话制作栏消耗 10 点生命制作 1 朵莲花，无需科技。这里的莲花不是食物：每朵可为混天绫补充 10 点燃料，也可拆开得到 莲子×1、花瓣×1。

莲池产出的莲藕和莲子是另一组可食用物，当前数值如下：

食物 普通人物食用 哪吒食用
莲藕 8 生命 / 25 饥饿 / 0 理智 三项均为 0
烤藕片 20 生命 / 25 饥饿 / 15 理智 三项均为 0
莲子 0 生命 / 4.6875 饥饿 / 0 理智 三项均为 0
烤莲子 1 生命 / 4.6875 饥饿 / 0 理智 三项均为 0

因此，“莲花”负责混天绫充能和拆分材料；“莲藕 / 烤藕片 / 莲子 / 烤莲子”才进入食用结算。哪吒食用这四种莲池产物都不会恢复三维。

乾坤圈

项目 规则
装备限制 仅哪吒可装备；其他玩家拾取会自动掉落
手持基础伤害 34
投掷射程 16 / 18；投射速度 14
投掷伤害序列 首个命中 50，之后依次为 45 / 40 / 35 / 30 / 25，后续维持 25
连锁规则 每命中一个目标后，在当前位置周围 8 格寻找未命中过的有效目标；最多命中 20 个目标
回收规则 找不到新目标或投掷落空时返回主人；哪吒处于飞行状态时会自动接住。手部空槽则自动装备，否则收入物品栏

乾坤圈会排除玩家、墙、随从等对象，而且同一次投掷不会重复命中同一个目标。

[腌笃鲜联动提示]：乾坤圈飞行时异常落水或落入虚空的问题会自动修复；“乾坤圈自动巡回”为独立可选项，默认关闭。详见神话优化。

腾云术：风火轮

哪吒亲自阅读灵台方寸山的天书后，会永久解锁名为风火轮的腾云入口。发动时消耗 25 点理智并直接进入共用飞行状态，不会制作出可放入背包或装备栏的独立物品。

项目 规则
飞行速度 10（高于地面基础移速；飞行时直接使用专属飞行速度）
火焰 飞行期间附带风火轮火焰效果，并将外部火焰伤害倍率设为 0
制作限制 除黑白无常外，飞行状态无法在地面选点建造；骑乘、冻结、睡眠等状态也会终止或阻止飞行
落地 对自身使用“落地”操作结束飞行

飞行用于赶图、越过地面阻碍、脱离地面压力和处理火焰环境；它不是全面的无敌。
