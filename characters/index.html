玉兔仙子

轻拢慢捻，十曲随心。玉杵生香，七味济人。玲珑仙兔，狡兔三窟。月宫守卫，闻弦而行。

人物身份

  • 玉兔是《腌笃鲜》的重置人物，不是对《神话书说》原玉兔的覆盖补丁
  • 新玉兔与《神话书说》原玉兔并存，两个人物拥有各自独立的角色身份、物品、进度与技能体系
  • 新玉兔的核心定位是广寒司乐：以莹月琵琶持续塑造团队BUFF覆盖，以捣药玉杵准备群体药效，并可通过月宫守卫兑现收益
  • 人物开放：服务器模组设置默认开放玉兔；关闭后玉兔不进入选人及换人列表，请勿在已有玉兔角色的世界中途关闭

  • 出生物品：莹月琵琶 ×1、捣药玉杵 ×1

技能栏

玉兔拥有独立技能栏，统一承载捣药、演奏模式、月宫守卫、遁地、腾云与狡兔三窟入口。

  • 技能栏会根据曲谱、守卫资格、腾云解锁和三窟次数动态显示按钮
  • 可在“暂停界面 → 设置 → 腌笃鲜”中选择显示或隐藏，并切换标准、大、小三档尺寸
  • 技能栏可拖动，位置会独立保存在本地，但不具备转换排列的功能
  • 琵琶按钮只切换普通演奏 / 长奏，不是曲目快捷键；长奏状态会显示“∞”

莹月琵琶：十曲随心

手持莹月琵琶右键打开官方样式曲目轮盘，选曲后进入节奏演奏。

项目 规则
开曲消耗 5点饥饿
小节消耗 每个小节结算后消耗1点饥饿，完美、普通、失败三档消耗相同
操作 按提示输入方向键（默认WASD），并在月标进入判定区时按下行动键（默认空格）
谱面难度 四档依次为3键、4键、5键与困难5键
完美 方向全部正确，并命中完美窗口
普通 错1个方向，或行动键只命中普通窗口
失败 未按行动键、行动键出窗，或方向错误超过1个
乐势变化 完美 +2；普通不变；失败 -2
神合 乐势达到4后进入；掉到4以下、停奏或换曲时立刻解除
满弦 乐势达到6且本节为完美时触发
作用范围 友方曲、敌方曲及流水无情均为25格；每个有效小节照料8格内农作物

普通演奏与长奏：

  • 普通演奏的乐势上限为6，触发满弦后自动收曲
  • 长奏的乐势上限为8，第一次在6点触发满弦后继续演奏
  • 长奏从6升到8只进入峰值，不重复奖励；已经处于8点时再次打出完美，才会再次结算满弦
  • 长奏失误后必须重新爬回8点，再以峰值完美重发满弦
  • 演奏开始后模式锁定，本次演奏中不能临时切换

本地声音设置：

  • 所有玩家均可在“暂停界面 → 选项 → 腌笃鲜”中将本机听到的玉兔琵琶音量设为正常、75%或50%；该设置不会改变其他玩家听到的音量
  • 玉兔还可单独开启或关闭完美、良好与失误的演奏反馈音；该设置不影响琵琶曲、轮盘开关音和其他玩家

基础效果的获得：

  • 友方增益曲若开曲4秒仍未出现完美，会在玉兔附近生成6枚可拾取音符
  • 本次演奏首次完美会自动把基础效果分发给有效范围内的友方，并清除尚未领取的音符
  • 敌对减益曲与场域支援曲不掉落地面音符，效果直接作用于实际目标
  • 已经获得的基础或满弦效果不会因玉兔停奏而回滚；神合属于演奏中的动态增强，停奏后立即消失

月宫守卫

月宫守卫是玉兔的常驻护卫与演奏兑现单位。

属性 数值
生命值 500

攻击间隔 2秒

死亡冷却 120秒
  • 初始没有守卫资格；首次学会任意一首非初始曲目后，上限解锁为1名
  • 掌握曲目总数达到9首后，上限直接提升为3名，没有2名阶段
  • 召唤或补充守卫消耗5点理智；达到上限后再次使用守卫按钮会召回当前守卫，召回不消耗理智
  • 右键守卫按钮可令全部当前守卫钻地归月，暂时停止跟随、战斗和劳作；之后左键守卫按钮可让它们一次重新出阵，归月与出阵均不消耗理智，也不会恢复生命或触发死亡冷却
  • 守卫默认以保护玉兔为主；演奏《怨缠身》《春风化雨》《霸王卸甲》时，会主动攻击16格内受曲目影响的敌人
  • 进入神合时，当前所有守卫立即恢复100生命
  • 满弦触发20秒“月华共鸣”：守卫获得50%减伤，攻击间隔缩短到1秒，攻击变为50普通伤害+50位面伤害
  • 《春光曲》《浴火奏》《寒风调》《梦飞霜》满弦时，演奏者当前已有的守卫同时获得20秒对应基础曲效；守卫不会获得玩家的满弦强化
  • 持有对应基础曲效的守卫，可被16格内任意友方玉兔的同曲神合继续增强，不要求演奏者是守卫主人
  • 这些临时曲效不会写入守卫存档；守卫死亡、召回、换洞或读档后会清除，新召守卫也不会追补此前的满弦奖励
  • 演奏《田中乐》时，守卫可砍树、采矿和清理树桩，不负责拾取资源；基础、神合、满弦工作量分别为1、2、4，且满弦效果会促使守卫自主劳作20秒

兔族亲和与狡兔三窟

  • 玉兔拥有兔子伪装：普通兔子不会因她靠近而逃跑，活兔可直接拾取
  • 玉兔不能主动谋杀或直接烹饪活兔
  • 随身携带至少1只活兔时获得中等理智回复，多只不会叠加
  • 玉兔直接造成兔子死亡时立即损失5理智；旁观20格内兔子死亡也会按距离在5秒内持续损失最多5理智，同一窗口不会反复叠满
  • 普通兔人与兔王不会仅因玉兔携带肉类主动仇恨她；若玉兔主动攻击、共享仇恨或带有其他敌对身份，兔族仍会正常反击
  • 玉兔不会仅因自身低理智把兔子、普通兔人及兔系外观看成梦魇形态；官方强制梦魇仍然有效

狡兔三窟：

  1. 将活兔给予一个未塌陷的兔洞，执行“放归”
  2. 每名玉兔每个自然日最多通过放归获得1次三窟次数
  3. 次数上限为3；达到上限或当天已经获得次数时，兔洞不会收走活兔
  4. 有次数时技能栏才显示“狡兔三窟”，并标注当前次数
  5. 使用后在合法地面打开官方兔子号角公用箱，成功生成箱子消耗1次

[当前规则]：新版玉兔不开放旧版“采集兔洞”或“量产兔洞”路线，这两项旧设定已经由狡兔三窟替代。

腾云

  • 前往灵台方寸山阅读天书后解锁，未解锁时技能栏不显示腾云按钮
  • 起云消耗25点理智，再次使用同一按钮按神话原腾云流程落云
  • 骑乘中不能起云，也不会被强制下牛或消耗起云理智
  • 若设置了腾云本地按键，可用同一按键起云与落云；技能栏仍可正常使用
  • 云上移动倍率为10/6，约1.67倍
  • 腾云期间每3秒恢复1点生命，并携带-10寒气效果
  • 杏花仙子与月桂酒香外观会在腾云时使用各自对应的专属云朵、特效与光效表现
  • 腾云与遁地互斥；云上仅保留落云能力，捣药、守卫、狡兔三窟和遁地等地面技能不可使用

广寒生态与专属制作

嫦娥与广寒宫：

  • 玉兔向嫦娥赠送宝石或大蟠桃时，额外增加1点好感
  • 每次成功完成基础好感赠礼后，有10%概率额外获得一枚月饼
  • 玉兔夜间可进入广寒宫，并不会因广寒夜间规则被驱逐
  • 向嫦娥展示曲目物品完成请教后，物品会返还；曲谱进度、守卫上限、腾云解锁与三窟次数均随人物存档保存

月蛾引路：

黑风大王·熊罴真身

黑风大王败而化风，本欲借遁法脱身。若以吞天紫金葫芦先一步锁住战败之地，黑风便无处可逃，妖王被迫显出熊罴真身。

触发条件

熊罴真身不能通过普通刷新直接出现，必须完成以下流程：

  1. 找到并挑战《神话书说》原黑风大王
  2. 在其死亡前，提前释放吞天紫金葫芦的“吞天控场”
  3. 必须等待吞天施法真正完成、活动场已经展开
  4. 让原黑风大王在活动场覆盖范围内真正战败
  5. 原黑风大王先按神话原流程完成死亡与掉落，随后生成的战败遁风会被吞天场截住
  6. 遁风无法逃走被控制在吞天施法点，并在那里显化熊罴真身

判定重点：

  • 先杀死黑风大王、再补放吞天无效
  • 吞天仍在蓄力、活动场尚未真正建立时击杀无效
  • 战败遁风从场外飘入吞天范围无效，判定只看原黑风死亡瞬间是否被活动场覆盖
  • 偷蜜入场风、黑风大王超时离场风均不是战败遁风，不能触发真身
  • 多个吞天场同时覆盖死亡点时，只由最近的一处取得触发权
  • 同一时间只会存在一场熊罴真身遭遇

黑风倒卷与风王冲山

生命低于70%后，真身会把石障从普通掩体升级为机制解题资源。

  1. 只有场上至少保有2座有效石障、没有尚未结束的黑旋，且存在位于真身超过10格、不超过14格处、未被石障遮挡并可被牵引的陆地玩家时，真身才会选择倒卷
  2. 真身先以完整动作蓄积黑风，中心风压逐渐扩大；起手后不会因为初始目标跑位而取消整招
  3. 正式吸入开始后，每次风压都会检查20格范围符合条件的玩家才会被快速拉向真身
  4. 进入约3格风眼的玩家被捕获并暂时失去移动
  5. 若至少捕获1人：真身锁定被捕获者，保证完成一次普通挥击；实际伤害判定结束后释放所有被捕获玩家
  6. 若最终无人被捕获：真身随即进入风王冲山
  7. 冲锋前会显示预警，玩家需要继续走位，把真身引向石障
  8. 真身撞碎石障后进入6秒硬直；若撞中玩家，则造成110普通伤害+15位面伤害并击飞
  • 骑乘玩家仍以玩家本体参与倒卷的起手、拉拽与捕获判定；保底挥击继续沿官方骑乘规则把伤害转移给有效坐骑，不会额外强制掉落坐骑

[机制要点]：石障背风侧只解决“倒卷抓人”；倒卷挡住后仍要完成第二步，引导冲山撞石。提前把所有石障耗尽会让这一组合失去正解。

万字黑风吼

真身生命首次跨过70%与35%时，各强制进行一次万字黑风吼。若一次高伤同时跨过两个阈值，第二次会排队等待，至少间隔6秒，不会无操作地背靠背立刻爆发。

爆发范围与伤害：

  • 判定范围为真身周围24格
  • 冲击波造成15普通伤害+5位面伤害
  • 每名玩家在爆发瞬间检查身体装备栏中的锦襕袈裟
  • 只放在物品栏里无效；爆发后才换上也无法解除已经产生的控制

穿着锦襕袈裟：

  • 完全免疫本次冲击波、硬控与后续普攻猎杀
  • 获得本次技能期间的黑风拉力免疫，并显示佛光护体
  • 结算中只要至少一名玩家成功护体，猎杀收束后真身会受到佛光反震，进入4秒输出窗口
  • 成功破解后会短时间提高真身对袈裟玩家的仇恨权重，给团队其他成员创造空间

未穿锦襕袈裟：

  • 先承受冲击波，再进入失去操作的心神控制
  • 真身只以普通挥击逐个猎杀被控制玩家，不插入黑旋、敲地、冲锋或连击
  • 同一玩家受到第2次真实普通攻击命中后解除控制
  • 控制最多持续12秒；玩家死亡、真身撞石硬直、真身死亡或挑战失败也会提前解除

石障保底：

  • 未穿袈裟但处于有效石障背风侧时，冲击波伤害降为35%，但仍会被控制
  • 猎杀期间若真身高速追击撞上石障，会触发6秒硬直并终止本轮控制
  • 石障不是锦襕袈裟的完全替代；无袈裟、无石障时，玩家会完整承受冲击波与至多两次普通攻击

挑战失败与返风

  • 真身以自身实时位置为中心检查60格范围内的存活玩家
  • 连续20秒没有任何存活玩家留在范围内，挑战判定失败
  • 宽限期间只要有存活玩家重新进入60格，失败倒计时立即取消
  • 失败后真身不会掉落任何奖励，会清理黑旋、石障、控制与技能状态，再次化作黑风离开
  • 下一次挑战必须重新完成偷蜜、击杀原黑风、预铺吞天场并在场内完成击杀的完整流程
  • 冻结、丢失当前攻击目标或短暂脱战不等于挑战失败，只看真身附近是否仍有存活玩家
